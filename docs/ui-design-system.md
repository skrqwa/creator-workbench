# 创作工坊 · 前端设计规范（黛青画册流 v2，已定稿）

本文档锁定 `creator-workbench` 的视觉方向、信息架构与前端实现约束。开发前端界面时须以此文档、[src/tokens.css](../src/tokens.css) 和 [docs/design-reference/](design-reference/) 为准，完成后按文末验收清单自检并提交审核。

---

## 1. 视觉锚点与核心原则

- **视觉定位**：「黛青画册流（Celadon Editorial Studio）」——宣纸月白底 + 雾青预览剧场 + 纯白活跃卡片 + 黛青墨绿主色，并内置同套令牌驱动的**夜墨深色主题**（`data-theme="dark"`），默认打开为宣纸浅色。
- **全中文界面**：所有导航、按钮、状态、表单与提示使用自然简明中文主动语态（如「导出成品」「去抖音复核」「用这个选题开始创作」），避免英文混排或技术黑话。
- **去后台模板化**：移除旧版 220px 左侧常驻菜单栏，改为 **64px 单行顶部流程导航**，让画布和作品始终占据主体空间。
- **视觉克制（防胶囊泛滥）**：每张卡片内同类参数收进单行控件条或行内语义文本，不堆叠多行彩色小标签。
- **单一令牌真源**：所有颜色、圆角、字栈与阴影一律从 [src/tokens.css](../src/tokens.css) 引入，禁止在组件样式里写死旧深蓝/亮橙色值。

## 3. 顶栏与全站信息架构

顶栏固定高度 `64px`，三段式栅格：

1. **左区**：印章图标「坊」+「创作工坊」+ 项目/工作区切换按钮（可打开项目库 [ProjectDialogs.jsx](../src/ProjectDialogs.jsx) 或新建项目）。
2. **中区**：4 个核心创作流程标签（底部 2px 黛青指示线）：
   - `选题灵感`（附条数徽标）→ [TopicsTools.jsx](../src/TopicsTools.jsx) `TopicsPage`
   - `内容创作` → [Editor.jsx](../src/Editor.jsx) `Editor`
   - `八平台分发` → [Publishing.jsx](../src/Publishing.jsx) `PublishPage`
   - `发布记录` → [AccountsReceipts.jsx](../src/AccountsReceipts.jsx) `ReceiptsPage`
3. **右区**：保存状态（`role="status" aria-live="polite"`，显示具体时刻如「刚保存 · 14:32」或「保存中…」）+ 日/夜主题切换图标钮 + `本机工具`（进入制作工具与发布账号管理页）+ 当前页唯一主按钮（创作页「导出成品」/ 分发页「批量核对」/ 选题页「新建空白作品」）。

## 4. 各核心页面布局与必做细节

### 4.1 内容创作页（[Editor.jsx](../src/Editor.jsx)）

左右黄金双栏（左栏约 `53%` 宣纸底 `--paper` 独立滚动，右栏约 `47%` 雾青底 `--mist` 固定视口）：

- **左栏（分镜故事卡片流）**：
  - 顶部：作品类型标签（`录屏教程` / `热点口播`）+ 宋体大标题（`--serif`，`text-wrap: balance`）+ 单行元信息（镜头数、总时长、自动同步说明）+ 待办快捷跳转（如有待配音镜头则显示「N 镜待配音 →」，点击跳至对应镜头）。
  - 折叠分镜卡：排序把手（同时保留键盘/按钮上移下移）+ 16:9 缩略图 + 编号与标题 + 单行截断旁白 + 时长胶囊与语义配音状态（图标 + 文字）。
  - 激活分镜卡：纯白底 `--card` + 左侧 `3.5px` 黛青竖条 + 大缩略图（角标显示推镜倍率与时长）+ 语义化 `<textarea>` 旁白编辑区（含字数/预估秒数）+ 内嵌声纹试听条（播放按钮 + 音频波形/进度 + 等宽时间 + 「重新配音」）+ **单行分镜控件条**（音色选择、推镜倍率、时长/跟随配音、纳入竖版、用作图文配图/补充稿）。
  - 底部虚线按钮：添加新分镜。
- **右栏（实时成片剧场 + 标志性「一稿四态」卡）**：
  - 顶部形态切换器：`横屏视频` / `竖屏短片` / `小红书图卡` / `长文`，右侧显示 `镜头 XX / YY`。
  - 16:9 实时预览舞台（支持推镜缩放框预览、实时字幕叠加）+ 章节分段式播控条（播放键 + 按镜头时长比例切分的进度段 + 等宽总时长）。
  - 本镜素材源条：显示当前画面来源（OpenScreen 录屏 / 图片 / 视频），提供「换画面」「重录本镜 / 导入 OpenScreen」。
  - **标志性模块「一稿四态 · 实时同步」**：用真实比例缩影（`16:9`、`9:16`、`3:4`、长文版式）展示四类导出形态及其长度/页数，点击可切换上方预览；底部一行汇总已就绪平台数并提供「前往八平台分发 →」。

### 4.2 八平台分发页（[Publishing.jsx](../src/Publishing.jsx)）

三栏布局（左 `278px` 平台清单 `--paper-2` / 中自适应编辑区 `--paper` / 右 `416px` 实景预览 `--mist`）：

- **左列**：顶部作品摘要 + 就绪进度条；下方列出全部 8 个平台（抖音、小红书、B站、微信视频号、微信公众号、快手、今日头条、知乎），每行使用低饱和圆标 + 平台名 + 内容形态 + **语义状态（图标 + 文字，不单靠圆点色）**。
- **中列**：当前平台大标题 + 目标账号切换 + 内容形态分段切换 +「从主稿重新同步」；纯白表单卡（真实 `<label>` + `<input>` 标题与字数计数 + `<textarea>` 正文 + 话题芯片）；封面与成片信息卡；底部发前自动核对条（明确列出通过/待补项）。
- **右列**：顶部「实景预览」+ **「安全区参考线」开关**（竖屏平台支持轻显 9:16 安全区虚线框，避开平台底部文案与右侧交互栏）；底部双按钮「去平台复核」与「确认并提交」，保留原有账号权限门禁与独立发布记录语义。

### 4.3 选题灵感页（[TopicsTools.jsx](../src/TopicsTools.jsx) `TopicsPage`）

左右双栏（左约 `55%` 选题流 `--paper` / 右约 `45%` 选中选题策划与立项 `--mist`）：

- **左列**：标题与同步状态 +「拉取更新」「随手记一条」（支持原 RSS / Atom / GitHub Releases / 手工收藏弹窗或展开面板）；单行分类筛选 + 搜索框；灵感卡片采用行内语义标签与来源日期，标出是否与往期作品相似。
- **右列**：选中选题的出处链接、平衡换行大标题、摘要/来源信息卡片、可选立项模板（`录屏教程` / `热点口播`）与「用这个选题开始创作 →」主按钮。

### 4.4 发布记录、制作工具、发布账号与弹窗

- [AccountsReceipts.jsx](../src/AccountsReceipts.jsx)、[TopicsTools.jsx](../src/TopicsTools.jsx) `ToolsPage` 与 [ProjectDialogs.jsx](../src/ProjectDialogs.jsx) 统一复用 `src/tokens.css` 令牌、宣纸底、纯白圆角卡片（`16px`）、语义图标状态和同一套按钮体系，保持全站浑然一体。
- 制作工具与发布账号可通过顶栏「本机工具」进入，内部用分段标签切换「制作工具（OpenScreen / Qwen 配音）」与「发布账号（八平台绑定）」。

## 5. 无障碍、排版与技术硬约束

1. **色彩与对比度**：正文与次要文字在日/夜模式下均满足 WCAG AA `>= 4.5:1`；绝不单靠颜色圆点传达状态，必须配图标或明确文字。
2. **语义与键盘**：交互动作一律使用 `<button type="button">`（导航使用 `<a>` 或显式 `role="tab"`），所有表单项绑定 `<label>`，纯图标按钮带 `aria-label`，装饰图标带 `aria-hidden="true"`，全站保留清晰的 `:focus-visible` 2px 黛青焦点环。
3. **排版细节**：所有时间码、字数、倍率与计数应用 `.tabular-nums`（`font-variant-numeric: tabular-nums`）；多行标题应用 `text-wrap: balance`；省略号使用 `…` 而非 `...`。
4. **动效与主题**：显式声明 `transition` 属性（严禁 `transition: all`）；尊重 `prefers-reduced-motion`；切换日/夜主题时同步更新 `document.documentElement.dataset.theme` 与 `<meta name="theme-color">`（日间 `#f7f5ef` / 夜间 `#101513`），并持久化到 `localStorage`。
5. **功能边界**：仅改造前端展示与交互体验，保持 `desktop/` IPC 协议、本地工程数据结构、导出链路与发布安全核对逻辑完整兼容。
